# Circuit Grind

Circuit Grind is a mobile-friendly study game built from the supplied course question sheets.

## Question banks

- Cable Installation & Testing — 50 questions
- CEC 2024 & Telecom Practice — 63 questions
- Structured Cabling Fundamentals — 50 questions
- Total — 163 questions

Handwritten selections on the sheets were ignored. The answer key was assigned independently. Questions with ambiguous wording, provincial or local dependencies, or requirements governed outside the CEC are visibly flagged **REVIEW** in the app.

## Modes

- **Hardcore:** one wrong answer resets the run to Question 1 and reshuffles the choices.
- **Practice:** answer feedback and technical explanations without resets.
- **Survival:** three lives.
- **Speedrun:** two-minute score attack.
- **Daily 10:** a repeatable question set generated from the current date.

The app also includes category filters, XP, streaks, achievements, themes, optional sound, keyboard controls, local statistics, progress export, and offline caching.

## Deployment

This folder is a self-contained GitHub Pages build. No package manager, framework, server, or build step is required. Open `index.html`, or serve the repository through GitHub Pages.

The readable source project is also available as the downloadable project archive produced with this build.

## Accuracy notice

This is a study aid, not an official code interpretation. Verify field work against the 2024 CEC edition adopted in the relevant province, provincial amendments, applicable building and fire codes, project specifications, listed product instructions, and the authority having jurisdiction.
