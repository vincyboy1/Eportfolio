# Electrical Wiring Unit 2 Study Guide

A guided, visual study site built from the supplied Learning Tasks 1-16, self-tests, and Unit 2 presentation.

## Study approach

- Short teaching sections organised around the drawing skill being learned.
- Clear job-site context for each idea, rather than recall questions before the material is explained.
- Interactive references for line types, scale conversion, and choosing the correct drawing in a set.
- Optional self-check prompts with an explanation available on demand.
- Progress markers stored only in the browser used for study.

## Publish update to GitHub Pages

Replace the matching files in your existing GitHub repository with this folder's contents and commit the changes to `main`.

Your existing **Deploy Circuit Sprint to GitHub Pages** workflow will rebuild and publish the updated site automatically. If GitHub Pages is not already set to **GitHub Actions**, set it once under **Settings → Pages**.
