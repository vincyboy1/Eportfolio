# Circuit Grind

Circuit Grind is a static, mobile-friendly study game built from the supplied course question sheets.

## Included question banks

- Cable Installation & Testing — 50 questions
- CEC 2024 & Telecom Practice — 63 questions
- Structured Cabling Fundamentals — 50 questions
- Total — 163 questions

Handwritten selections on the sheets were ignored. The answer key was assigned independently. Questions with ambiguous wording, jurisdictional dependencies, or requirements governed outside the CEC are visibly marked **Review flag** inside the app.

## Modes

- **Hardcore:** one wrong answer resets the run to Question 1 and reshuffles question and answer order.
- **Practice:** answer feedback and explanations without resets.
- **Three Lives:** three misses end the run.
- **Speedrun:** two-minute score attack with a five-second wrong-answer penalty.
- **Daily 10:** deterministic daily question set.

The app also includes XP, ranks, streaks, achievements, boss questions, random supply-crate bonuses, topic filters, keyboard controls, local statistics, progress export, colour themes, optional sound, and offline caching.

## Deployment

No framework or build step is required. GitHub Pages can serve the `study-quiz` folder directly as part of the repository site.

## Accuracy notice

This is a study aid, not an official code interpretation. Verify field work against the 2024 CEC edition adopted in the relevant province, provincial amendments, applicable building and fire codes, project specifications, listed product instructions, and the authority having jurisdiction.
