# Circuit Sprint

An interactive study site built from the supplied Level 1 electrical learning tasks and self-tests. It is designed for short, focused practice blocks rather than long reading sessions.

## What is inside

- Eight compact missions covering symbols, diagrams, drawing conventions, construction prints, manuals, and material takeoffs.
- A one-question quick-fire drill with explanations and a saved streak.
- An eight-minute focus timer and on-device progress tracking.
- A shuffled 15-question mock test for the end of the week.

## Publish with GitHub Pages

1. Put this folder in a GitHub repository and push it to the `main` branch.
2. In GitHub, open **Settings → Pages** and set the source to **GitHub Actions**.
3. The included workflow publishes the site automatically after each push.

The workflow works for both a normal project repository and a `username.github.io` repository.
